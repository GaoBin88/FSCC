# FSCC: Flow Spatially Clustered Coefficient Model

Supplementary code, data, figures, and result tables for the research paper **“Modeling Spatial Heterogeneity in Origin–Destination Flows: A Penalized Fusion Approach to Spatially Clustered Coefficients.”**

The FSCC framework identifies spatially clustered, flow-specific regression coefficients in origin–destination (OD) data. It uses three classes of spatial fusion links and cyclic coefficient updates with inner ADMM iterations. This repository includes simulation experiments and an empirical application to interprovincial migration in China.

## Method overview

For each directed flow `(i,j)`, FSCC allows regression slopes to vary across OD pairs. It defines three kinds of flow adjacency:

- **E1:** flows with the same origin and spatially adjacent destinations.
- **E2:** flows with the same destination and spatially adjacent origins.
- **E3:** flows with spatially adjacent origins and spatially adjacent destinations.

An elementwise L1 fusion penalty encourages connected flows to share coefficient values. Estimation uses cyclic coefficient-block updates; the fused-lasso subproblems are handled by ADMM. Distinct coefficient surfaces may have different fusion partitions.

### Simulation

The simulation design considers `n = 100`, `200`, and `300` regions on rectangular Rook grids of dimensions `10 × 10`, `10 × 20`, and `15 × 20`, respectively. The main off-diagonal simulations use `N = n(n-1)` directed flows and compare FSCC with the Spatially Weighted Interaction Model (SWIM).

**Important:** The simulation notebook contains multiple complete program versions, including test runs and older variants. Select the intended `B = 30` experiment for each region count; do **not** run the entire notebook indiscriminately. Check that the selected version excludes within-region flows (`i == j`) and uses the evaluation procedure described in the paper.

### Empirical application

The empirical notebook analyzes 930 directed flows among 31 provincial-level units in China. The regression includes origin and destination GDP, population and investment, and a geographical distance covariate. The regression distance is **different** from the minimum distance between provincial polygons used to construct the regional adjacency matrix.

The empirical adjacency criterion uses a 10 km threshold for minimum polygon distance. Base fusion weights are normalized separately by edge class, and the intercept is first estimated by global ordinary least squares (OLS) and then held fixed during FSCC fitting rather than fused.

## How to run

1. Download or clone this repository.
2. Change the working directory to **`FSCC_SUPPLEMENTARY/`**, the folder containing the notebooks and `sevenpopulation.csv`:

   ```bash
   cd FSCC_SUPPLEMENTARY
   jupyter lab
   ```

3. For simulation, open `FSCC_simulation_Rook_adjacent.ipynb` and run only the relevant complete experiment block.
4. For the empirical analysis, open `FSCC_EMP_ROOK.ipynb`; check the CSV file path and **replace the Windows-specific absolute Shapefile path** with the location of your provincial polygon dataset. The Shapefile and its companion files are required but are not included in the currently supplied project inputs.
5. Review the outputs and save or move figure files into `fig/` and result tables into `output_results/`.

**Output-path note:** In the supplied notebooks, files are generally written to the current working directory. The folders `fig/` and `output_results/` organize exported outputs but are not automatically used as save locations unless the relevant `savefig()`/`to_csv()` paths are changed.
